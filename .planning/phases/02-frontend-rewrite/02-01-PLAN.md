<task type="auto">
  <name>Task 2: Add Content-Security-Policy header to security_headers middleware</name>
  <files>src/server.rs</files>
  <action>
    In `src/server.rs`, in the `security_headers` middleware function (lines 58-69), add one additional header insertion AFTER the existing four security headers:

    ```rust
    headers.insert(
        "Content-Security-Policy",
        HeaderValue::from_static(
            "default-src 'self'; script-src 'unsafe-inline'; connect-src 'self'; base-uri 'none'; frame-ancestors 'none'; form-action 'none'"
        ),
    );
    ```

    Rationale per SEC-05:
    - `default-src 'self'` — all resources (images, fonts, styles) from same origin only
    - `script-src 'unsafe-inline'` — required because the JS is embedded directly in assets.rs HTML string (keep inline pattern per user decision)
    - `connect-src 'self'` — fetch() to same-origin API only (explicit override of default-src)
    - `base-uri 'none'` — prevent injection of base tags
    - `frame-ancestors 'none'` — prevent framing (clickjacking)
    - `form-action 'none'` — prevent form submissions (all API calls use fetch)

    Add a test in the `tests` module:
    ```rust
    #[tokio::test]
    async fn test_csp_header_present() {
        let res = test_router()
            .oneshot(Request::builder().uri("/").body(Body::empty()).unwrap())
            .await
            .unwrap();
        let csp = res.headers().get("Content-Security-Policy").unwrap().to_str().unwrap();
        assert!(csp.contains("default-src 'self'"));
        assert!(csp.contains("script-src 'unsafe-inline'"));
        assert!(csp.contains("base-uri 'none'"));
        assert!(csp.contains("frame-ancestors 'none'"));
        assert!(csp.contains("form-action 'none'"));
    }
    ```

    Place this test near the other security headers tests (around line 357).
